Resource estimation: how many qubits and gates real problems need

“How big a quantum computer would we need to simulate nitrogenase?” In 2017 the answer involved about 101410^{14}1014 T gates. By 2021 the logical cost had fallen to about 5×1095\times10^95×109 Toffoli gates on 2,142 logical qubits, and the physical estimate to about four million physical qubits running for under four days. Neither the molecule nor the target accuracy changed. This chapter shows where the savings came from and lets you rebuild the estimate.

On the plate: a resource calculator for a chemistry problem.

From logical to physical

The pipeline is Chapter 143’s, applied to chemistry. Logical counts come from the algorithm: qubits for the orbitals, the block encoding and phase register; Toffolis from the number of walk steps, πλ/2ε\pi\lambda/2\varepsilonπλ/2ε, times the cost of each step. Then pick a code distance so that the whole computation fails with probability below about 1%, add magic-state factories, and multiply out. The estimate depends most strongly on four inputs: the Hamiltonian’s 1-norm λ\lambdaλ (set by the factorization), the target precision ε\varepsilonε (chemical accuracy), the physical error rate, and the code cycle time. Established as method.

Rebuild the FeMoco estimate

Logical qubits 2150, Toffolis 10^9.7, physical error 10^-3.0, cycle 1 µs, reaction 10 µs, plain surface code. With Lee and colleagues’ 2021 logical counts, the book’s simplified model gives distance 31, about 4.5 million physical qubits and about two days: close to their detailed “about four million qubits, under four days”. Move the Toffoli count to 101410^{14}1014, the 2017 regime, and the run time becomes over a century. Lower the error rate to 10−410^{-4}10−4 and the distance halves, to 15, so the footprint falls to about a quarter, near 1.1 million qubits. Established as a calculation; the model is simplified.

Where the savings came from

From 2017 to 2021, roughly: replacing Trotter steps with qubitization, which removes Trotter error and its overhead; factorizing the Coulomb interaction to cut the 1-norm λ\lambdaλ, first by single then double factorization and then tensor hypercontraction; and better arithmetic for loading Hamiltonian coefficients. Later work explored cat-qubit architectures, where biased noise reduces overhead (Chapter 141), and ever-cheaper magic states (Chapter 140). The same pattern appeared for factoring RSA (Chapter 143). The lesson: resource estimates are moving targets, typically falling by orders of magnitude as algorithms improve, so a single number in a press release says little without its date and assumptions. Hardware able to run them does not yet exist. Speculative for the hardware.

What you now have

The chemistry resource pipeline, the four most sensitive inputs, a calculator that reproduces the 2021 FeMoco physical estimate, and the sources of the roughly twenty-thousand-fold drop in logical cost since 2017.
