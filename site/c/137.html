Part Three · D · Error correction and fault tolerance

Quantum codes: Shor, Steane, CSS

In the early 1990s many physicists believed quantum error correction was impossible, for three good reasons. You cannot copy a quantum state to make redundant copies (no-cloning). Errors are continuous, an infinity of tiny rotations, not discrete flips. And checking for errors means measuring, which destroys the superposition you were trying to protect. In 1995 Peter Shor found a code that defeats all three objections at once. The trick is to measure only the error, never the data.

On the plate: Shor’s nine-qubit code. Damage it any way you like and watch it heal.

The nine-qubit code

Shor nested two repetition codes. Against bit flips, copy the basis state (not the amplitudes) across three qubits: ∣0⟩→∣000⟩|0\rangle\to|000\rangle∣0⟩→∣000⟩, ∣1⟩→∣111⟩|1\rangle\to|111\rangle∣1⟩→∣111⟩; this is entanglement, not cloning. Against phase flips, do the same in the ∣±⟩|\pm\rangle∣±⟩ basis. Together:

∣0L⟩=122(∣000⟩+∣111⟩)⊗3∣1L⟩=122(∣000⟩−∣111⟩)⊗3\begin{gathered}|0_L\rangle = \tfrac{1}{2\sqrt2}(|000\rangle + |111\rangle)^{\otimes3}\\ |1_L\rangle = \tfrac{1}{2\sqrt2}(|000\rangle - |111\rangle)^{\otimes3}\end{gathered}∣0L​⟩=22​1​(∣000⟩+∣111⟩)⊗3∣1L​⟩=22​1​(∣000⟩−∣111⟩)⊗3​

Eight stabilizers check the code: six of the form ZiZjZ_iZ_jZi​Zj​ within each block, comparing neighbours’ bit values, and two of the form X⊗6X^{\otimes6}X⊗6 across pairs of blocks, comparing block signs. Every codeword is a +1 eigenstate of all eight, so measuring them reveals nothing about α\alphaα and β\betaβ. Established

The general conditions, and CSS codes

Emanuel Knill and Raymond Laflamme gave in 1997 the condition for a code with projector PPP to correct a set of errors {Ea}\{E_a\}{Ea​}:

PEa†EbP=cabPPE_a^\dagger E_bP = c_{ab}PPEa†​Eb​P=cab​P

Errors must not distinguish codewords, and must map the code to spaces that are either orthogonal or identical in effect. Correcting X, Y and Z on a qubit suffices to correct any error on it, because every operator is a combination of those four. Robert Calderbank and Shor, and Andrew Steane, independently in 1996, showed how to build quantum codes from two classical codes C2⊂C1C_2\subset C_1C2​⊂C1​: use one for bit flips and the dual of the other for phase flips. From the [7,4,3] Hamming code (Chapter 136), which contains its own dual, comes the Steane code [[7,1,3]]: seven qubits, one logical qubit, distance 3, with the Hamming checks used once as X-type stabilizers and once as Z-type. Established

Three questions to carry with you.

How does the Shor code avoid cloning?tap
It entangles basis states, |0⟩ → |000⟩, rather than copying an unknown state.
Why doesn’t syndrome measurement destroy the data?tap
Every codeword has the same stabilizer eigenvalues, so the outcome carries no information about α, β.
How are continuous errors handled?tap
Measuring the syndrome projects them onto discrete Pauli errors, which are corrected.
