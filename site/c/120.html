HHL and quantum linear algebra, with input/output caveats

Solving a system of linear equations, Ax=bA\mathbf x = \mathbf bAx=b, underlies almost all of scientific computing, from finite-element models of bones to the reconstruction of CT images. In 2009 Aram Harrow, Avinatan Hassidim and Seth Lloyd gave a quantum algorithm whose cost grows only logarithmically with the number of unknowns: an exponential speedup. The algorithm is correct. But the speedup comes with conditions so restrictive that Scott Aaronson wrote an article called “Read the fine print.” This chapter reads it.

On the plate: a checklist. Describe your problem, and see whether an exponential advantage survives.

How HHL works

Load b\mathbf bb as a quantum state ∣b⟩|b\rangle∣b⟩. Run phase estimation (Chapter 113) with eiAte^{iAt}eiAt to write each eigenvalue λj\lambda_jλj​ of AAA into a register. Rotate an ancilla by an angle proportional to 1/λj1/\lambda_j1/λj​, uncompute the eigenvalue register, and keep the result when the ancilla reads 1. What remains is proportional to A−1∣b⟩=∣x⟩A^{-1}|b\rangle = |x\rangleA−1∣b⟩=∣x⟩. The cost is about log⁡N⋅s2κ2/ε\log N\cdot s^2\kappa^2/\varepsilonlogN⋅s2κ2/ε, with sss the sparsity (non-zeros per row) and κ\kappaκ the condition number, the ratio of largest to smallest eigenvalue. The fine print

Set your problem: size 6 (log₁₀ unknowns), condition number 2.0 (log₁₀ κ). Then answer: input is or ; output needed is or ; matrix is or .

Each caveat can erase the advantage. Loading NNN arbitrary numbers into amplitudes costs about NNN operations, unless a special memory device exists. Reading out the full vector needs about NNN repetitions, since each run yields one sample. A dense matrix stored as data has the same loading problem. And if κ\kappaκ grows with NNN, as it does for many discretized differential equations, the speedup shrinks to polynomial. Established

Where it might still matter

The favourable cases are those where the matrix and the right-hand side come from a compact physical description, and you want a global property of the solution: the average stress in a region, a scattering amplitude, the probability that a particle is in a cell. Recent work targets linear differential equations in physics and engineering on this basis. Whether practically valuable problems fit all the conditions, at sizes where the quantum overhead pays off, is open. Debated

Three questions to carry with you.

What does HHL output?tap
A quantum state |x⟩ proportional to the solution, not the numbers themselves.
Why does loading classical data cancel the speedup?tap
Preparing an arbitrary N-amplitude state costs about N operations.
What is the condition number’s role?tap
Cost grows with κ; if κ grows with N, the advantage shrinks.
