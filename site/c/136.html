Part Three · D · Error correction and fault tolerance

Classical error correction

The Voyager probes, now beyond the edge of the solar system, send data home with a transmitter weaker than a fridge light. Your phone reads a QR code with a coffee stain on it. Both work because the data carry redundancy arranged so cleverly that errors can be found and fixed without knowing in advance where they will strike. Quantum error correction borrows every idea in this chapter, then has to overcome three obstacles classical codes never face.

Hamming’s code and syndromes

Richard Hamming, frustrated by weekend computer jobs failing at Bell Labs, found in 1950 a code that protects 4 data bits with only 3 extra bits. The generator matrix GGG maps 4 data bits to a 7-bit codeword; the parity-check matrix HHH satisfies HGT=0(mod2)HG^\mathsf T = 0 \pmod 2HGT=0(mod2), so every codeword has zero syndrome HcH\mathbf cHc. A single flipped bit produces a syndrome equal to that bit’s column of HHH, which names the culprit. The decoder never looks at the data, only at parities. Flip probability 0.050, then . The code is distance 3: any two codewords differ in at least 3 places, so it corrects one error per block. Its rate, 4/7, beats repetition’s 1/3. Established

Distance, rate, and LDPC codes

A code [n,k,d][n, k, d][n,k,d] encodes kkk bits into nnn with distance ddd, correcting ⌊(d−1)/2⌋\lfloor (d-1)/2\rfloor⌊(d−1)/2⌋ errors. Codes trade rate k/nk/nk/n against distance, and Claude Shannon’s theorem (Chapter 95) says the best codes approach channel capacity. Robert Gallager’s 1962 low-density parity-check (LDPC) codes approach it in practice: each check involves only a few bits and each bit only a few checks. Decoding uses belief propagation: bits and checks pass probability messages along the edges of the code’s Tanner graph until they agree. Rediscovered by David MacKay in the 1990s, LDPC codes now run in Wi-Fi, 5G and satellite TV. Their quantum versions, and belief-propagation decoders for them, are the subject of Chapter 141.
