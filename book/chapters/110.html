You are handed a sealed box computing a function {{tex:f}} on {{tex:n}}-bit strings, promised to be either constant (same output for every input) or balanced (0 for exactly half the inputs). To be certain which, a classical computer may need to ask {{tex:2^{n-1} + 1}} questions. A quantum computer needs one. That is the Deutsch–Jozsa algorithm, the first clear quantum speedup. It is also a cautionary tale: a classical computer that is allowed to guess, and be wrong one time in a million, needs only about twenty questions. Separations in this oracle model are real, but you must ask exactly what they are separating.

Oracles and phase kickback

A classical function is made reversible as {{tex:U_f|x\rangle|y\rangle = |x\rangle|y\oplus f(x)\rangle}} (Chapter 94). Put the output qubit in {{tex:|-\rangle = (|0\rangle - |1\rangle)/\sqrt2}}: flipping it multiplies it by −1, so

{{texd:U_f|x\rangle|-\rangle = (-1)^{f(x)}|x\rangle|-\rangle}}

The function value has been kicked back into a phase on the input. Apply this to a superposition of all inputs and every {{tex:x}} gets its own sign, in a single query. That is the engine of every algorithm in this part. Established

The honest comparison: a deterministic classical algorithm needs {{tex:2^{n-1} + 1}} queries in the worst case; a randomized one that checks {{tex:k}} random inputs is wrong with probability at most {{tex:2^{1-k}}}. So the exponential gap is only against exact classical algorithms. David Deutsch posed the one-bit version in 1985; Deutsch and Richard Jozsa generalized it in 1992. Established

Bernstein–Vazirani

Now {{tex:f(x) = s\cdot x \bmod 2}} for a hidden string {{tex:s}}. Classically, each query reveals at most one bit of {{tex:s}}, so you need {{tex:n}} queries, even with randomness. The same circuit, one query, outputs {{tex:s}} exactly, because the Hadamard transform of {{tex:(-1)^{s\cdot x}}} is a single spike at {{tex:s}}. Hide 5 (as three bits) and run it. Ethan Bernstein and Umesh Vazirani introduced it in 1993; their recursive version gave the first super-polynomial oracle separation against randomized classical computers.

What oracle separations mean

Query complexity counts calls to a black box and ignores everything else. It allows clean, provable separations, which are otherwise rare in complexity theory. But real problems don’t come in black boxes: someone must build the oracle as a circuit, and if the function is simple enough to write down, a classical computer may exploit its structure directly. Oracle separations show what quantum mechanics can do; whether a real problem benefits is a separate question, asked again in every chapter that follows.
